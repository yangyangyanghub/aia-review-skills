# 校审质量门禁

| 阶段 | 可继续的条件 | 阻塞时的处理 |
|---|---|---|
| G0 数据处理 | 材料类别、当前会话环境与本次处理范围相容 | 停止受影响内容处理，输出授权/环境缺口；不尝试云端兜底 |
| G1 基线 | 图纸批次、来源哈希、定位、单位与读取能力可追溯 | 补清单/受控转换；其余来源可单独继续 |
| G2 依据 | 项目条件、版本、适用日期/过渡、条文条件可核验 | 对应 check=unverified_basis；不猜数字 |
| G3 专业执行 | 计划项逐一有状态；疑点、正常与未评估分别统计 | 缺输入/不支持/错误保留并指定补充路径 |
| G4 闭环 | 每项疑点有真实人工处置；修改经当前基线复查 | 待定、仅回复、未复查仍阻塞审签准备 |
| G5 审签准备 | 重算哈希、更新影响项、材料和记录完整 | ready 仅交人工正式审签；内部工作稿随时可导出 |

安全风险的低置信疑点应优先补证，不因证据不够就移出报告。对本轮约定范围外内容明确列出边界，不把它伪装成 not_applicable。

覆盖口径：计划数 N；evaluated、not_applicable、insufficient_input、unsupported、unverified_basis、error 之和=N。已求值率=evaluated/N；适用项求值率=evaluated/(N-not_applicable)，分母为 0 时报告“不适用/无适用项”，不报告 100%。有疑点率不是准确率。

知识库、规则库、模型、提示词、资料批次或处理工具变更后，根据影响范围重跑；不要因一个无关标点改动无限扩大复查。正式释放前必须再次核对对应文件哈希。文件哈希可防错误关联，不能替代有效签名或证明文件从未被恶意修改。
