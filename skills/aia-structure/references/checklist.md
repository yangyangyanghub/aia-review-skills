# 结构与计算书辅助校审候选检查表

此表是工作检查范围，不含规范阈值，不宣称覆盖全部条款。按地域、用途、阶段和专项要求增删，增删理由进入范围文件。执行每项前核验依据与适用条件；表中编号可作计划 ID 前缀。

必需资料：勘察报告、结构设计说明、基础/主体图、荷载表、计算模型输入与输出、软件及版本、专项分析、构件详图。改造增加检测鉴定、既有结构证据和新增荷载。

| ID | 对象 | 必要输入 | 比较与证据要求 | 易错边界 |
|---|---|---|---|---|
| ST-01 | 场地与基础参数 | 地勘版本、场地参数、地下水、基础图 | 核对采用层位、参数、基础形式和标高 | 勘察建议不能脱离适用层位 |
| ST-02 | 结构体系与设防 | 设计条件、体系、规则性、专项要求 | 核对分类及相应设计条件在说明/模型一致 | 没有专项结论不填“满足” |
| ST-03 | 荷载与组合 | 用途、设备、构造重量、荷载表 | 核对来源、分项口径、组合与工况覆盖 | 不能混用标准值、设计值、包络值 |
| ST-04 | 模型与图纸 | 轴网、层高、截面、材料、边界 | 逐层对应构件、连接、支承及传力路径 | 计算书封面一致不证明模型一致 |
| ST-05 | 分析结果解释 | 工况和组合编号、位移/内力结果 | 核查结果对应的假定、控制工况和警告 | 单个指标不足以判断整体安全 |
| ST-06 | 构件与配筋 | 控制内力、承载计算、配筋详图 | 抽核同一构件的截面、材料、筋量与构造 | 不按图面粗线猜钢筋直径 |
| ST-07 | 节点与连接 | 节点详图、连接件、锚固和焊接 | 核对受力路径及相关构造条件 | 节点示意需计算与详图支撑 |
| ST-08 | 基础与地下工程 | 基础计算、抗浮、支护等专项接口 | 核对水位、工况、沉降和主体接口 | 基坑/支护范围须明确专项责任 |
| ST-09 | 设备洞口及非结构构件 | 洞口表、设备反力、支吊架和幕墙条件 | 逐项核对承载与局部加强的条件输入 | 不自行同意现场开洞或切筋 |
| ST-10 | 改造与施工阶段 | 检测鉴定、拆改顺序、临时工况 | 核对新增作用、保留条件和临时支承需求 | 不能从旧图直接推断实际现状 |

记录示例：“本版图 A 的 X 部位标注为……；图 B 相同对象标注为……；两者批次/口径已经核对，存在待专业确认的不一致。”未读到数据就保留缺口，不填演示数字。

每个结论应能由另一位审查人用原来源复现。发现可能影响生命安全的事项即使证据置信程度低，也交责任人优先核实，并保留缺失信息。
