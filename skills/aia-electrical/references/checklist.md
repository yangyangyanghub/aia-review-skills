# 电气与消防联动辅助校审候选检查表

此表是工作检查范围，不含规范阈值，不宣称覆盖全部条款。按地域、用途、阶段和专项要求增删，增删理由进入范围文件。执行每项前核验依据与适用条件；表中编号可作计划 ID 前缀。

必需资料：用电与供电条件、负荷分级和计算、供配电单线图、设备与电缆表、配电平面、保护计算、接地防雷、应急照明与疏散指示、火灾报警和联动矩阵。

| ID | 对象 | 必要输入 | 比较与证据要求 | 易错边界 |
|---|---|---|---|---|
| EL-01 | 供电与负荷条件 | 供电批复、用途、设备表、负荷分级 | 核对负荷等级及其设计依据和实际对象 | 等级由适用条件决定，不凭名称推定 |
| EL-02 | 负荷与电源容量 | 负荷计算、功率因数、需用系数、工况 | 复算口径及与各专业设备功率一致性 | kW 与 kVA 不能直接相等 |
| EL-03 | 供电路径与备用 | 单线图、切换、备用源和末端 | 逐路径核查独立条件、切换与覆盖对象 | 线条数量不能证明供电可靠性 |
| EL-04 | 线路与保护 | 长度、敷设、截面、负荷和保护计算 | 核对电压损失、载流与短路/保护口径 | 缺敷设和环境参数保持未评估 |
| EL-05 | 接地和防雷 | 类别、接地系统、等电位、连接节点 | 核对系统边界、导体、连接和专业接口 | 单个接地电阻指标不足以判断完整性 |
| EL-06 | 应急照明与指示 | 布点、系统、供电、控制及路径 | 沿实际疏散路线核对设备与状态 | 不能以符号密度代替照度或可视性计算 |
| EL-07 | 火灾报警与联动 | 设备 ID、触发分区、矩阵及控制图 | 逐条核对报警—动作—反馈—手动接口 | 文字说明与矩阵矛盾需两侧引用 |
| EL-08 | 消防与关键设备 | 各专业设备表、配电和控制回路 | 交叉核对额定/运行功率及供电控制需求 | 不能因设备接入就假定消防工况可用 |
| EL-09 | 电气空间与通道 | 变配电、竖井、桥架与检修路径 | 核对安装、维护、穿透与其他系统接口 | 三维净空和隔离条件需实际几何 |

记录示例：“本版图 A 的 X 部位标注为……；图 B 相同对象标注为……；两者批次/口径已经核对，存在待专业确认的不一致。”未读到数据就保留缺口，不填演示数字。

每个结论应能由另一位审查人用原来源复现。发现可能影响生命安全的事项即使证据置信程度低，也交责任人优先核实，并保留缺失信息。
