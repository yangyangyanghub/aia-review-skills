# 暖通与防排烟辅助校审候选检查表

此表是工作检查范围，不含规范阈值，不宣称覆盖全部条款。按地域、用途、阶段和专项要求增删，增删理由进入范围文件。执行每项前核验依据与适用条件；表中编号可作计划 ID 前缀。

必需资料：用途与人数、气象参数、负荷计算、冷热源、空调通风系统和平剖、风量/阻力计算、防烟分区、防排烟计算、设备选型及联动说明。

| ID | 对象 | 必要输入 | 比较与证据要求 | 易错边界 |
|---|---|---|---|---|
| HV-01 | 设计工况与房间条件 | 气象、用途、人数、运行时段 | 核对负荷/新风条件与建筑用途 | 条件缺失不凭常用值填入 |
| HV-02 | 负荷与冷热源 | 负荷模型、分区、设备能力及工况 | 核对输入、同时使用口径和选型工作点 | 铭牌总能力不是设计工况能力 |
| HV-03 | 新风与排风平衡 | 房间风量、排放、补风路径 | 按房间与系统核对流向、量和平衡 | 不能只用系统总量证明各室可用 |
| HV-04 | 防烟排烟适用范围 | 空间条件、防烟分区、消防用途 | 与建筑分区核对边界、开口和适用条件 | 建筑/防火/防烟分区不同概念 |
| HV-05 | 消防气流与计算 | 计算、风口、补风、泄压、设备曲线 | 逐消防工况核对路径、风量、压差与阻力 | 一个总量不代表全部工况 |
| HV-06 | 风道穿越与阀件 | 平剖、分隔、阀门及检修 | 查穿透、耐火、关闭/开启与检修接口 | 阀件符号不证明联动动作正确 |
| HV-07 | 联动与供电 | 火灾触发、动作、反馈及负荷表 | 与电气消防逐行核对设备 ID 和状态 | 普通停机与消防启动逻辑要区分 |
| HV-08 | 安装净空和检修 | 机房、设备、风管、支吊架和剖面 | 核对安装/保温/检修空间和通道 | 几何碰撞之外还查维护包络 |
| HV-09 | 噪声冷凝与节能接口 | 消声、排凝、保温及控制 | 核对设备位置、排凝路径与围护穿越 | 声学指标需说明边界和计算证据 |

记录示例：“本版图 A 的 X 部位标注为……；图 B 相同对象标注为……；两者批次/口径已经核对，存在待专业确认的不一致。”未读到数据就保留缺口，不填演示数字。

每个结论应能由另一位审查人用原来源复现。发现可能影响生命安全的事项即使证据置信程度低，也交责任人优先核实，并保留缺失信息。
